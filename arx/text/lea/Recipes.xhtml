Recipes

Practical, task-oriented recipes for building real-world ebooks with Lea. Each recipe shows how to combine Lea tags and scripts for a concrete outcome, and why you might choose one approach over another.

Table of Contents

Use the lea:script named toc to insert a linked table of contents into a text, or toc plain for an alphabetized, link-free list.

Author Biographies

Use the list authors script to build a back-matter chapter of author biographies from block files.

Cover Image Placement

Use lea:cover in the ebook definition file to declare the cover image, and lea:image inside texts to place illustrations.
