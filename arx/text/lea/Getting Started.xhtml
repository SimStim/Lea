Getting Started

Installation

What you need

PHP ⊙8.5 or newer with the dom, mbstring, zip, and curl extensions. Clone or download the Lea repository and run composer install to fetch dependencies.

One-liner setup


cd Lea
composer install]]>
Arx Structure

Lea expects the arx/ folders under the current working directory: arx/ebooks/ for the ebook definition, arx/text/ for text files, arx/styles/ for stylesheets, and arx/images/ for images.

First Project

Invocation

Run lea.php from the repository root with your ebook definition file:

The first argument is the ebook definition file (relative to arx/ebooks/). The optional check-epub argument runs EPUBCheck after compilation.

Minimal ebook definition

A minimal lea.xml needs a lea:title, at least one lea:author, and at least one lea:text declaration.

Text file requirements

Every text file needs its own lea:title and at least one lea:author.
