Glossary

Terms used throughout this documentation. Lea assumes the reader is familiar with publishing and EPUB concepts, but this glossary is here for reference.

EPUB

Electronic publication format. Lea produces EPUB 3.3 with EPUB 2 backward compatibility.

content.opf

The EPUB package document: lists every file in the EPUB, its metadata, and the reading order.

manifest

The section of content.opf that lists every file included in the EPUB.

spine

The section of content.opf that defines the reading order of the EPUB.

nav.xhtml

The EPUB 3 navigation document: clickable table of contents for modern reading systems.

toc.ncx

The EPUB 2 navigation file: table of contents for older reading systems. Lea includes it for backward compatibility.

container.xml

Entry point of the EPUB package, located at META-INF/container.xml. Points reading systems to content.opf.

OPF

Open Packaging Format. The XML format used by content.opf.

NCX

Navigation Centered XML. The XML format used by toc.ncx in EPUB 2.
